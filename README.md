# santkrupa

Open Marathi saint literature — public-domain texts, free to reuse.

Code in this repo is Apache License 2.0. Texts are NOT Apache: public-domain originals are PD-marked, Wikisource-derived transcriptions are CC BY-SA 4.0 with attribution to Wikisource. Each work has a SOURCE.md with author, source, licence, and proofing status.

## Pilot works
- Haripath — Dnyaneshwar, 30 sections in this edition (proofing needed)
- Pasaydan — Dnyaneshwar, 9 ovis
- Changdev Pasashti — Dnyaneshwar, 65 ovis
- Manache Shlok — Samarth Ramdas, 205 shlokas

All content is Devanagari text. No scans, no PDFs, no binaries are published here.
